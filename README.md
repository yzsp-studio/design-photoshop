## 🇨🇳 中文

在 Photoshop 里完成排版、精修与合成：从零排版、照片精修、商品合成、参考图重建，到已有 PSD 续改和画布素材交接。默认交付真实的分层文档（PSD/PSB），同时把可视预览回传画布，图层、蒙版和可编辑文字都保留可继续修改的结构。开始时先明确交付意图——源版本、要改的内容、尺寸、屏幕或印刷用途，以及必须保留可编辑的元素；只在答案会改变执行时才问询，等待期间继续检查素材。只有明确要求使用 PS 或编辑其文档时才适用，「PS 风格」「海报风」、风格参考或知识问答都不触发该流程。

### ✨ 能做什么

- 简报 / 照片 / 参考素材 → 分层 PSD/PSB，可继续修改
- 覆盖新建排版、照片精修、商品合成与参考图重建
- 已有 PSD 续改与画布素材交接，沿用既有工程约定
- 先看图层结构再定方案，动手前落实可编辑结构
- 明确屏幕或印刷用途与尺寸，印刷要求提前问清
- 可视预览回传画布，图层命名不改动画面原文

## 🇬🇧 English

Handles layout, retouching and compositing in Photoshop — from-scratch design, photo retouching, product compositing, reference rebuilding, edits to an existing PSD and canvas asset handoff. The default deliverable is a real layered PSD/PSB with a visual preview returned to the canvas, so layers, masks and editable text stay reworkable. It starts by pinning down the delivery intent: source version, what changes, dimensions, screen or print use, and the elements that must remain editable. Questions are asked only when an answer changes execution, and asset checks continue while waiting. It applies only when PS or its documents are explicitly required; a 'PS look', 'poster style', style references or knowledge questions do not qualify.

### ✨ What it does

- Brief, photo or reference in; layered PSD/PSB out and still editable
- Covers from-scratch layout, photo retouching, product compositing and reference rebuilds
- Extends existing PSDs and hands off canvas assets under the project's own conventions
- Plans from the layer structure and fixes an editable structure before touching pixels
- Clarifies screen or print use and dimensions, including printer requirements
- Returns a visual preview to the canvas without translating existing layer names
